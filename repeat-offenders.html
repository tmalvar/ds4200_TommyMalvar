Number of Repeat Offenders per Sport

This visualization shows the number of repeat offenders by each sport. A repeat offender is a team that forfeited more than once in a season.

The sports with the most repeat offenders are Badminton and 4v4 Volleyball, with 16 repeat offenders. The sport with the fewest is Ice Hockey, at 1.

Most of the sports with more players required ended up with fewer repeat offenders, whereas sports with fewer players required had more repeat offenders. Therefore, it is possible that there are certain individuals to blame for the forfeit problem in Northeastern intramurals, not necessarily an entire team.
